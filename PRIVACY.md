# Privacy

Last updated: 1 August 2026

Drinking Democracy is designed to keep ordinary gameplay data on the device.

## Data handled by the app

- Player names, language preference, cached prompt packs, and played-card history are stored locally with AsyncStorage.
- Prompt packs are downloaded from the project’s public GitHub repository. GitHub may process normal request metadata, such as IP address and user-agent information, under its own privacy terms.
- Choosing “Submit a prompt” opens the device’s email application with a draft addressed to the project. Nothing is sent automatically. If the player sends it, the prompt, selected mode, and optional social handle are processed by the player’s and project’s email providers.

The current code does not include advertising, analytics, account creation, or a custom data-collection backend.

## Deleting local data

Removing the application clears its locally stored gameplay data. Players can also replace names and language preferences from within the application.
