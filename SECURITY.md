# Security policy

## Reporting a vulnerability

Please report security or privacy issues privately to `drinkingdemocracy@gmail.com`. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not include exploit details, personal information, signing credentials, or store secrets in a public GitHub issue. Acknowledgement and remediation timing will depend on severity and the ability to reproduce the report.

## Supported version

Security fixes target the latest code on `main` and the most recently published store build.
